## Espacio físico para la Feria de Ciencias

### Dimensiones del stand

- **5 metros de ancho × 4 metros de profundidad**

### Hardware

| Elemento | Cantidad | Uso |
|----------|----------|-----|
| Computadora | 1 | Ejecutar el juego (conectada a WiFi o por cable Ethernet) |
| Monitor para el jugador | 1 | El participante juega mirando esta pantalla |
| Monitor para ranking | 1 | Pantalla extra mostrando el ranking en tiempo real |
| Proyector | 1 | Proyectar la partida para que el público vea |
| Parlantes | 1 | Sonido inmersivo del juego |
| Zapatillas eléctricas | Varias | Enchufes para toda la komponente |

### Decoración y elementos físicos

- **Posters / infografías** explicando el proyecto
- **Volante impreso en 3D** con sensores Arduino para la experiencia inmersiva
- **Decoración general** del stand relacionada al juego

### Conectividad

- La PC debe estar conectada a **WiFi o mediante cable Ethernet** (necesario para el ranking en tiempo real y la publicación en itch.io)
